# API Processamento Pedidos
Desafio do Padrões de Projeto (Design Patterns) da DIO, em participação do projeto do bootcamp Itaú, de Java com IA.

### 🚀 Implementações

#### ☕ Java puro

* Singleton
* Strategy
* Facade

#### 🌱 Spring Boot

* REST API
* Persistência com H2
* Singleton
* Strategy
* Facade
* CRUD de pedidos
* Estratégias de pagamento: PIX e cartão
* Relacionamento Cliente → Pedidos
* Arquitetura organizada em Controller / Service / Repository / Model
